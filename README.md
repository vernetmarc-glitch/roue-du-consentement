# Kiff Kiff — ancienne adresse

Le jeu Kiff Kiff vit maintenant sur **https://kiff-kiff.fr** (dépôt `vernetmarc-glitch/kiff-kiff`).

Ce dépôt ne sert que l’ancienne adresse `https://vernetmarc-glitch.github.io/roue-du-consentement/` :
une page de passage qui emporte, dans le « # » du lien (jamais envoyé à un serveur), ce que chaque
téléphone gardait ici (parties à deux, prénoms, ambiance) et ouvre la même page sur kiff-kiff.fr.
Les anciens liens d’invitation, les QR codes déjà partagés et les applis déjà installées continuent ainsi de marcher.
